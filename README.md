# ts-utils

## How to Install
```
    npm i @alarido/ts-utils
```

## Features
`compares`
 * Complex in-depth comparison of objects.
 * Recognize zeroes, empty values, empty objects.

`dates`
 * Parse date from string using customisable format.
 * Format supports: yyyy (year), mm (month), dd (day), hh (hour), ii (minutes) and ss (seconds).
